**Sep 2024 – Mar 2025** | Universo Prematuro® (Volunteer)

Contributed to a digital health initiative providing guidance, information, and evaluation tools for families of premature infants.

## Project Overview

Universo Prematuro® is a mobile application designed to:
- **Monitor premature infants** at home through structured assessments
- **Empower caregivers** with reliable developmental guidance
- **Evaluate child development** milestones
- **Reduce healthcare inequities** by providing accessible information

## Technical Contributions

- **Mobile Development:** Built mobile application features for iOS and Android
- **Backend Services:** Developed backend services for data management and processing
- **DevOps & Infrastructure:** Managed Docker containerized environments
- **Performance Monitoring:** Created service performance dashboards for system observability
- **Full-stack Implementation:** End-to-end development from database to user interface

## Technical Stack

- Mobile frameworks (Swift/Kotlin or cross-platform)
- Backend services and APIs
- Docker containerization
- Performance monitoring and observability tools

## Impact

Contributed to improving access to child development information and monitoring for families with premature infants in Brazil.
